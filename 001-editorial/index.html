Incremental Sync

Sinkronisasi produk incremental — hanya download yang berubah sejak timestamp terakhir.

Ringkasan

Modul sync.rs handle sinkronisasi produk dari server ke lokal. Sebelumnya: download ALL 7505 produk tiap sync. Sekarang: hanya yang updated_at > since.

Data Model

struct RemoteProduk {
    id: String,
    nama: String,
    harga: i64,
    updated_at: Option<String>,  // ← baru
}

Alur

  • First sync: since=null → full pull semua produk
  • Sync berikutnya: since=last_sync_ts → hanya yang berubah
  • Server query: WHERE updated_at > since
  • Client: upsert ke DB lokal, update sync_produk_at
  • Retry 2× kalau fetch gagal

API

GET /api/produk?semua=1&since=2026-10-08T12:00:00Z

Response: [{ id, nama, harga, updated_at }]

Backwards compatible: tanpa since = full pull.

Pitfall

  • ⚠ Ganti tenant → reset sync_produk_at, wajib full pull
  • ⚠ updated_at harus ada DB trigger auto-update
  • ⚠ Jika server belum deploy ?since=, client fallback full pull
